# InkoHoreca — сторінки під рекламу

Три готові сторінки, одна дизайн-система, один скрипт на зображення.

```
get-photos.py        ← запустити один раз, наповнює всі три сторінки
data/products.json   ← каталог: 11 товарів, ціни, артикули, посилання

landing/index.html      Лендинг під пошукову кампанію — 9 блоків за брифом
advertorial/index.html  Адверторіал «6 reasons» — редакційний, під холодний трафік
offer/index.html        Hybrid-stat офер — за структурою референсу PetLab
```

Кожна сторінка — **один самодостатній HTML**. Ніяких збірок, залежностей, CSS-файлів.
Поруч лежить `assets/` з фотографіями.

## Крок 1 — зображення

З машини, яка бачить inkohoreca.com:

```bash
python3 get-photos.py
```

Скрипт робить три проходи:

1. **Фото товарів** — з публічного фіду `/products.json`, розкладає по 37 слотах усіх трьох сторінок
2. **Логотипи мереж** — знімає з головної в `*/assets/logos/`
3. **Решта великих зображень** — у `candidates/`, звідки берете лайфстайл-кадр на hero

HTML не редагується. Поки файлу немає — на його місці векторний малюнок у брендових
кольорах, тож сторінка ніколи не виглядає порожньою.

## Крок 2 — що замінити руками

| Що | Де | Чому не автоматично |

## Дизайн-система

Все з `Inko HoReCa · Brand & UI Guideline v1.0` (14.09.2026):

- **Jost** 400/600/700, заголовки 600 з розрядкою `0.04em`, без капсу
- `#0E3E74` як рама, `#032A56` анонс-бар, `#333333` текст, `#E7E4DD`/`#F3F5F8` секції
- Amber `#D9941A` — один сигнал на екран, текст на ньому завжди `#000000`
- Шкала кеглів зі зламом на 700px, spacing кратний 4px, радіуси 4/8px
- **Без тіней** — у темі всі shadow-токени з альфою 0
- Кольори як RGB-канали: `rgb(var(--accent) / .12)`, жодного HEX поза блоком токенів
- `:hover` у `@media (pointer:fine)`, гілка `prefers-reduced-motion`, видимий focus
