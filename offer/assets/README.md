# assets/

Сторінка шукає тут фотографії. Поки файлу немає — на його місці малюнок у брендових
кольорах, тож сторінка ніколи не виглядає порожньою. Щойно файл з'являється — він на місці,
**правити HTML не потрібно**.

## Найшвидший спосіб — одна команда

З машини, яка бачить inkohoreca.com:

```bash
cd assets
python3 get-photos.py
```

Скрипт робить три речі: тягне головні фото товарів з публічного фіду вашого магазину
(`/products.json`), знімає з головної сторінки логотипи мереж у `logos/`, а решту великих
зображень складає в `candidates/` — щоб було з чого вибрати hero. Потрібен лише Python 3,
без залежностей.

## Які файли потрібні

| Файл | Що на кадрі | Пропорції |
|---|---|---|
| `hero.jpg` | Накритий стіл: меню-ковер і чек-презентер з однієї шкіри | 4:3 |
| `set.jpg` | Комплект разом — меню, презентер, фолдер, настільне | 1:1 |
| `compare.jpg` | Зношений ковер поруч із брендованим | 5:4 |
| `deal.jpg` | Герой офера — комплект на світлому тлі | 5:3 |
| `closer.jpg` | Крупно тиснення логотипу | 5:4 |
| `extra-menu-covers.jpg` `extra-folders.jpg` `extra-desk.jpg` `extra-inserts.jpg` | Міні-пакшоти | 1:1 |
| `case-1.jpg` … `case-5.jpg` | П'ять реалізованих проєктів | 3:4 |
| `logos/marriott.svg` `hilton.svg` `hyatt.svg` `radisson.svg` | Логотипи мереж, монохром | — |

## Логотипи мереж

Скрипт шукає їх на головній вашого сайту за назвою у шляху файлу і кладе в `logos/`.
Якщо у вашій темі вони називаються інакше — усі інші зображення з головної впадуть
у `candidates/`, звідти достатньо перейменувати потрібні у `logos/marriott.svg`,
`hilton.svg`, `hyatt.svg`, `radisson.svg`.

## Hero

Фід товарів віддає пакшоти на білому. Для hero краще лайфстайл-кадр — він теж буде
у `candidates/`. Скопіюйте потрібний поверх `hero.jpg`.
