# Скіли для створення адверторіалів (Advertorial / Listicle Framework)

Цей архів містить 5 скілів (SKILL.md), які разом складають наскрізний фреймворк для створення адверторіалів під холодну аудиторію — від Dream Outcome до готового HTML-файлу, готового до хостингу.

## Що всередині

```
skills/
  listicle-step1-dream-outcome/SKILL.md      — Крок 1: Dream Outcome
  listicle-step2-persona-awareness/SKILL.md  — Крок 2: Персона + Awareness (0-1) + Метод
  listicle-step3-product-analysis/SKILL.md   — Крок 3: Аналіз продуктової сторінки
  listicle-step4-advertorial/SKILL.md        — Крок 4: Текст адверторіалу
  listicle-step5-advertorial-html/SKILL.md   — Крок 5: HTML-адверторіал
```

Кожен файл — це окремий скіл (SKILL.md), який Claude використовує автоматично, коли розпізнає відповідний етап роботи. Файли не містять додаткових ресурсів (шаблонів, скриптів) — це чисто текстові інструкції-скіли.

## Логіка фреймворку

Це послідовний 5-крокoвий процес. Кожен наступний крок спирається на дані з попереднього:

**Крок 1 → Крок 2 → Крок 3 → Крок 4 → Крок 5**
`Dream Outcome → Персона+Awareness+Метод → Аналіз продукту → Текст адверторіалу → HTML`

1. **Dream Outcome** — фіксується бажаний результат покупця, ніша, тип продукту, гео, мова. Проводиться легка розвідка ринку (2 запити) — контекст і кілька впізнаваних брендів у категорії.

2. **Persona + Awareness + Метод** — повністю автономний крок (не залежить від інших). Три частини:
   - дослідження реальної мови аудиторії через web search (форуми, відгуки, Reddit-аналоги, Quora/блоги) → синтез 3-5 персон;
   - вибір ОДНІЄЇ персони → побудова Awareness Ladder тільки на рівнях 0 (Unaware) і 1 (Problem Aware) з реальними цитатами;
   - вибір 1-3 методів розробки адверторіалу (FB Ads Library / Майнінг функцій / Тригери моменту / Руйнування міфів / Експертний кут).

3. **Аналіз продуктової сторінки** — потрібен URL сторінки, на яку веде адверторіал. Витягується ціна/пакети, гарантія, формат доставки, фічі, credibility, social proof, поточний CTA. Проводиться Gap Check — чи справді сторінка підтверджує те, що обіцяно болю персони.

4. **Текст адверторіалу** — збирається готовий текст за форматом LE.Team: 5 блоків (Above the Fold → Value Proposition → Credibility → Social Trust → Star Offer), правило 70/30, "тест гірки", 5-10 варіантів хедлайна, карта покриття болей. Цей крок НЕ верстає HTML.

5. **HTML-адверторіал** — верстка тексту в одну сторінку у редакційному/журнальному стилі: стаття з байлайном, без CTA-кнопок до останнього блоку. Єдиний явно рекламний елемент — блок Star Offer з однією кнопкою, що веде на реальний URL продукту з Кроку 3.

## Як застосувати цей архів у новій сесії Claude / Cowork

1. Створіть (або відкрийте) проєкт Claude, у який хочете додати ці скіли.
2. Завантажте файли `SKILL.md` з папки `skills/` як документи проєкту, або передайте цей архів Claude у розмові й попросіть "збережи ці скіли в проєкт" — Claude використає інструмент збереження скілів (`propose_skills`), який покаже картку підтвердження, і після вашого підтвердження скіли з'являться у списку доступних.
3. Після збереження скіли автоматично підхоплюються Claude, коли ви працюєте над адверторіалом — вручну викликати їх не потрібно, достатньо описати задачу своїми словами (наприклад, "хочу зробити адверторіал для крем-сироватки").

### Варіант Б — ручне підключення (для розробників Claude Code / плагінів)
1. Розпакуйте архів.
2. Скопіюйте папки з `skills/listicle-step1-dream-outcome` по `skills/listicle-step5-advertorial-html` у директорію скілів вашого проєкту Claude Code (зазвичай `.claude/skills/` або аналогічну директорію плагіна).
3. Переконайтеся, що кожна папка містить файл `SKILL.md` з frontmatter (name/description) — це і є весь необхідний вміст, додаткових файлів не потрібно.
4. Перезапустіть сесію Claude Code / оновіть список скілів (`ToolSearch` / `RefreshMcpTools` за потреби), щоб нові скіли зʼявилися в переліку доступних.

### Важливі нюанси процесу
- **Не пропускайте кроки.** Скіли розраховані на послідовне проходження — крок 2 (персона) неможливий без зафіксованої ніші з кроку 1, крок 4 (текст) — без персони й аналізу продукту.
- **Web search — обов'язкова частина**, а не опція. Основний обсяг пошуку припадає на Крок 2 (дослідження аудиторії) і частково на Крок 3 (аналіз продукту, за потреби — FB Ads Library через Chrome MCP).
- **Не можна вигадувати цитати, відгуки чи дані сторінки.** Якщо чогось не вистачає — це або шукається ще раз, або явно позначається як "ДЕМО / замінити реальними даними перед запуском".
- **Gap Check на Кроці 3 критичний**: якщо продуктова сторінка не підтверджує те, що обіцяно болю персони — це сигнал доопрацювати сторінку або змінити кут/метод, а не "натягувати" текст.
- **Правило 70/30 і відсутність CTA-кнопок до фінального блоку** — головні маркери якості адверторіалу; порушення цих правил на Кроці 4-5 означає, що текст/верстку треба перезібрати.
- Якщо змінюється щось на ранньому кроці (наприклад, ніша на Кроці 1 або персона на Кроці 2), наступні кроки потрібно перезібрати каскадом — деталі в описі кожного скіла.
